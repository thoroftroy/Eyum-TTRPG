For convenience, this table shows what you gain at each level, up to level 30. Levels continue past 30. Keep following the pattern described in [[Eyum TTRPG/3.0 Character Management/3.3 Leveling Up|3.3 Leveling Up]].

Special bonuses from individual Skill Tree Levels (the Path and Archetype perks you purchase with your SKL) are not shown here, only the automatic leveling bonuses and the Bonuses you get each level for having any levels in the Magical, Physical or Utility Paths. See [[Eyum TTRPG/3.0 Character Management/3.3 Leveling Up|3.3 Leveling Up]] for the full skill trees. The table assumes you take the Proficiency Upgrade instead of the +2 Skill Points, and the Expertise Upgrade instead of the +5 Skill Points, when given the choice.
